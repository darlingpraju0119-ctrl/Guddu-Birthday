## 🚀 Quick Start

### Prerequisites
- A GitHub account (free)
- The 5 photo files to personalize

### Deployment on GitHub Pages

1. **Create a public GitHub repository**
   - Go to [github.com/new](https://github.com/new)
   - Name it (e.g., `guddu-birthday`)
   - Set it to **Public**
   - Click "Create repository"

2. **Upload the project files**
   - Upload `index.html`, `style.css`, `script.js`
   - Upload the `assets` folder with all 5 photos (keep folder structure intact)

3. **Enable GitHub Pages**
   - Go to **Repository Settings** → **Pages**
   - Under "Build and deployment"
   - Choose **"Deploy from a branch"**
   - Select **`main`** branch and **`/ (root)`** folder
   - Click **Save**

4. **Access your site**
   - GitHub will provide a free URL: `https://yourusername.github.io/guddu-birthday`
   - Share the link with Guddu! 🎉

## 🎨 Customization Guide

### Change Personalization Details
Edit `index.html` to replace:
- **Name:** Change "YUKTHI M" to the birthday person's name
- **Nickname:** Change "GUDDU" to their nickname
- **Story text:** Update all dialogue and personal messages
- **Birthday letter:** Modify the heartfelt message section

### Replace Photos
1. Prepare 5 images (recommended: 500x500px or similar square format)
2. Place them in the `assets/` folder
3. Update image paths in `index.html` to match your filenames
4. Keep the Polaroid styling—CSS handles the frame automatically

### Add Audio File
The site currently links to YouTube. To use a local audio file:
1. Add your audio file (`.mp3` or `.ogg`) to `assets/`
2. Modify the JavaScript in `script.js` to use a local player instead of the YouTube link
3. Ensure you have permission to use the audio file

### Adjust Styling
- Edit `style.css` to change colors, fonts, and layout
- Mobile breakpoints are built in—test on different screen sizes
