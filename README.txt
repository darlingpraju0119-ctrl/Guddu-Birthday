FREE HOSTING
GitHub Pages supports static HTML/CSS/JavaScript sites on GitHub Free public repositories.
1. Create a GitHub account.
2. Create a public repository, e.g. guddu-birthday.
3. Upload index.html, style.css, script.js and the assets folder.
4. Repository Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select main and "/" (root), then Save.
7. GitHub will publish a free github.io project URL.

Keep the assets folder with the photos exactly as supplied.
